# Troubleshooting software, installs and Microsoft Office

## A program will not install or the installer fails
What it usually means: a standard account cannot install, the disk is full, a previous install is half done, or the installer is blocked by security.
Common codes: 1603 (a fatal error during install), 0x80070005 (access denied), 0x80070070 (not enough disk space), 1618 (another install is running).
Try this: restart, free disk space, wait for other installs to finish, and run the installer again. Do not turn off antivirus.
Tobi can: check whether the program is already installed, check whether it is on the approved software list, and install an approved program after you approve.
Call IT when the program is not on the approved list: raise a software request.

## Is a program installed and which version?
Tobi can: search the installed programs by name and show the version and publisher, and list programs installed in the last days.

## A program was working yesterday and not today
What it usually means: an update changed something, a setting changed, or a service stopped.
Try this: restart the computer, check for recent changes, repair the program from Settings > Apps > Installed apps > the program > Advanced options > Repair.
Tobi can: list what was installed or updated recently, and show recent crashes of that program.

## A program is not responding or crashes at startup
What it usually means: a damaged installation or a conflicting add-in.
Try this: start it in safe mode if it has one, update it, repair it, then reinstall.
Tobi can: show recent crashes and close it after you approve.

## Office says "product activation failed" or "unlicensed product"
What it usually means: you are signed in with the wrong account, the licence is not assigned, or the clock or internet is wrong.
Try this: sign out of Office and sign in with your work account under File > Office Account, check the date and time, and restart the app.
Tobi can: check the clock and the connection.
Call IT when the licence is not assigned to you: raise a software request.

## Excel, Word or PowerPoint is slow, frozen or crashed
What it usually means: a very large file, a heavy formula or macro, an add-in, or low memory.
Try this: wait, then close and reopen. Office recovers unsaved work on reopening. Open in safe mode by holding Ctrl while starting, disable add-ins, and save a copy of the file.
Tobi can: show memory use and close a frozen Office app after you approve.

## A file is read-only or cannot be saved
What it usually means: the file is open somewhere else, it is on a read-only location, the disk is full, or you lack permission.
Try this: close the file elsewhere, save a copy with a new name in Documents, and check the disk space.
Tobi can: check free disk space.

## Recover an unsaved or overwritten Office file
Try this: reopen the program and look in the Document Recovery pane, choose File > Info > Manage Document > Recover Unsaved Documents, and check the version history if the file is on OneDrive or SharePoint.

## PDF problems: will not open, will not print, or asks for a password
What it usually means: a damaged file, a protected file, or no PDF reader.
Try this: open in Edge, try another PDF reader, and ask the sender for a copy without the password restriction.
Tobi can: check the file for being empty, damaged or protected.

## Uninstall is stuck
What it usually means: the uninstaller needs administrator rights or is broken.
Call IT: uninstalling software is done by IT. Tobi can raise the ticket.

## Browser is slow, shows errors or will not load a site
What it usually means: a large cache, extensions, or an old version.
Try this: clear the cache, disable extensions, update the browser, and try a private window.
Tobi can: clear the Edge or Chrome cache after you approve.

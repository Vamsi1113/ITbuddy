# Troubleshooting files, storage, OneDrive and shared drives

## OneDrive is not syncing or shows a red X or "sync pending"
What it usually means: you are offline, the account needs signing in again, a file name has a character OneDrive cannot sync, a file is open in a program, or the OneDrive storage is full.
Try this: click the OneDrive icon in the taskbar and read the message, check the internet connection, sign in again if asked, close the file that is open, and shorten very long file names. Pausing and resuming sync often restarts it.
Tobi can: test the internet connection and check free disk space.
Call IT when OneDrive reports an error code, giving them the code.

## I deleted a file by mistake
What it usually means: the file may still be in the Recycle Bin or in OneDrive's recycle bin.
Try this: open the Recycle Bin and restore the file. For OneDrive or SharePoint use the site's Recycle bin, and Restore your OneDrive within 30 days if many files vanished. Also check File History or a previous version.
Tobi can: show how big the Recycle Bin is. It never empties it without your approval.
Call IT when the file is not in any recycle bin: IT may restore it from a backup.

## "The file is in use by another program" and cannot be deleted or moved
What it usually means: a program, a preview pane or a background process has the file open.
Try this: close programs that might hold it, close the Explorer preview pane, wait a minute, and try again. Restarting the computer releases it.
Call IT when it is a system file or a file that needs administrator rights.

## Disk is full or "low disk space"
What it usually means: downloads, temporary files, the Recycle Bin, caches and large files fill the drive.
Try this: empty the Recycle Bin, delete or move large downloads, and run Storage settings cleanup.
Tobi can: find large temporary folders and user folders by size, clean old temporary files, empty the Recycle Bin and clear app caches, each after you approve.

## A shared or network drive is missing or will not connect
What it usually means: you are not on the office network or VPN, the share name changed, or the sign-in expired.
Try this: connect the VPN, then open the drive again or map it from File Explorer > This PC > Map network drive. Sign in with your work account.
Tobi can: test whether the file server answers.
Call IT when the drive is reachable for others but not for you: it may be a permission.

## A USB drive or SD card is not recognised or asks to be formatted
What it usually means: a loose connection, a dirty or damaged drive, a policy that blocks USB storage, or a damaged file system. Do not format it if you need the files.
Try this: try another USB port and another computer, and check Disk Management through IT. Only company-approved encrypted drives may hold company data.
Tobi can: list USB devices and whether Windows reports a problem.
Call IT when the drive holds files you need.

## A file is corrupted or will not open
What it usually means: the file was damaged during a save or copy, or it is a type your computer cannot open.
Try this: open it in its own program, try a recent version from OneDrive or a backup, and open it in another program.
Tobi can: check whether the file is empty or damaged for common types.

## Search in File Explorer finds nothing
What it usually means: the search index is rebuilding or the folder is not indexed.
Try this: wait after an update, search inside the folder you expect, and restart.
Call IT when search never finds files in indexed folders.

## A file name is too long or has a character that is not allowed
What it usually means: Windows paths have a length limit and some characters (< > : " / \ | ? *) are not allowed.
Try this: shorten folder and file names and remove those characters.

## Move large files to free space
What it usually means: a work folder or video files use a lot of space.
Try this: move large files to a network or cloud folder, and ask IT for more storage if you need it.
Tobi can: show which user folders are the largest.

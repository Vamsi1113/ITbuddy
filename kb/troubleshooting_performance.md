# Troubleshooting a slow or freezing computer

## How to find what makes a computer slow
A computer is slow when something is out of a resource: processor (CPU), memory (RAM), disk space or disk speed, or heat. Check in this order: how long since the last restart, how much memory is in use, which program uses the most, how full the disk is, and whether the fan is loud.
Tobi can: measure CPU, memory and uptime, name the program using the most memory, check free disk space, and close a program or clean temporary files after you approve.

## Computer is very slow overall
What it usually means: memory is nearly full, a program is using too much, the disk is almost full, or the computer has not been restarted for many days.
Try this: save your work, close programs you do not need, close extra browser tabs, restart the computer, and check that updates are not installing in the background.
Tobi can: show memory and CPU use, name the biggest program, and close it after you approve. Unsaved work in that program is lost, so save first.
Call IT when the computer is slow right after a restart with nothing open.

## Memory (RAM) is almost full
What it usually means: too many programs or browser tabs, or one program leaking memory (growing the longer it runs).
Try this: close programs and tabs, restart a program that has grown very large such as a browser, Teams or Outlook, and restart the computer.
Tobi can: name the largest closable program and close it after you approve.
Call IT when memory is always high on a new computer: it may need more RAM.

## Disk shows 100 percent usage
What it usually means: Windows Update, a backup or scan is running, a program writes constantly, or the disk is almost full.
Try this: wait ten minutes after startup, pause cloud sync, close heavy programs, and free disk space.
Tobi can: check free space and clear approved temporary files, the Recycle Bin and app caches.
Call IT when it stays at 100 percent for hours: the drive may be failing.

## CPU is high and the fan is loud
What it usually means: a program is working hard, a scan or update is running, or the computer is hot because vents are blocked.
Try this: close the busy program, place the laptop on a hard flat surface, clear dust from vents, and keep it out of direct sun.
Tobi can: show which program uses the most processor.
Call IT when the fan runs loudly with nothing open: it may need cleaning or repair.

## Slow startup or sign-in
What it usually means: many programs start with Windows, a large profile or network drives load, or an update finishes in the background.
Try this: open Settings > Apps > Startup and turn off programs you do not need, and restart once after updates.
Tobi can: open the Startup apps settings page and report the uptime.

## A program is not responding or frozen
What it usually means: the program is busy, waiting for a network file, or crashed.
Try this: wait a minute, then close the program from the Task Manager (Ctrl+Shift+Esc), and reopen it. Autosave often recovers your work.
Tobi can: close a frozen program after you approve.
Call IT when the same program freezes every day: check recent crashes with Tobi.

## Browser is very slow
What it usually means: too many tabs, heavy extensions, or a large cache.
Try this: close tabs, disable extensions one by one, and clear the browser cache.
Tobi can: clear the Edge or Chrome cache after you approve.

## Low disk space
What it usually means: downloads, temporary files, the Recycle Bin and large files fill the drive.
Try this: empty the Recycle Bin, delete old downloads, and move large files to a network or cloud folder.
Tobi can: find large temporary folders, clean old temporary files, empty the Recycle Bin and clear app caches, each after you approve.
Call IT when the drive is full of files you need and cannot move.

## Battery drains fast or the laptop will not charge
What it usually means: high background use, screen brightness, a worn battery, or a faulty charger or port.
Try this: lower brightness, close heavy programs, use battery saver, try another outlet and charger, and check the cable and port for damage.
Tobi can: read the battery status.
Call IT when the battery report shows low capacity or the charger is not recognised.

## Computer restarts or shuts down by itself
What it usually means: overheating, a failing power supply or battery, a driver crash, or an update restart.
Try this: check for dust and heat, install pending updates, and note the time it happens.
Tobi can: read the event log for unexpected shutdowns and crash reasons.
Call IT when it repeats: the logs point IT to the cause.

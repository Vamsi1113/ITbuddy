# Software and email

Sample knowledge-base article for the Tobi demo. Replace with your company's real guidance.

## Install software
Only IT installs software. Approved programs are listed in the software catalogue.
Ask Tobi "is <program> approved?" and then to raise a software request ticket.
Programs that are not in the catalogue need a security review, which takes up to five working days.

## Outlook does not open or keeps asking for a password
Close Outlook, restart the computer and try again. Check that the date and time are correct.
If it keeps asking for a password, sign out of Office under File > Office Account and sign in again.

## Set an out-of-office reply
In Outlook choose File > Automatic Replies, select "Send automatic replies" and type your message.
Set the date range so it switches off by itself.

## Shared mailbox or shared folder access
The owner of the mailbox or folder must approve. Ask Tobi to raise an access request ticket
and name the mailbox or folder and its owner.

## Teams or browser is slow or shows old content
Clearing the app cache often helps. Ask Tobi to "clear the Teams cache" or "clear the Edge cache".
Close the app first. Sign-ins and bookmarks are kept.

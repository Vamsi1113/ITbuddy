# Workstation housekeeping and temporary files

## Scope

Applies to all company laptops and virtual desktops in every ODC.

## Temporary files

- When temporary files use more than 1 GB, the user is alerted and asked to clean them.
- Only the Windows temporary folders may be cleaned (the user's TEMP folder and C:\Windows\Temp).
- Files changed in the last 60 minutes and files in use must not be deleted.
- The Downloads, Documents, Desktop, Pictures and OneDrive folders must never be cleaned automatically.
- Cleaning needs the user's consent each time. Automatic cleaning without asking is allowed only on shared kiosk PCs.

## Disk space

When the system drive has less than 10% free space, the user should clean temporary files first, then empty the
Recycle Bin, then raise a ticket if space is still low. Users must not delete files from Program Files or Windows
folders.
